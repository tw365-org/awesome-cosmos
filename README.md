## 🇹🇼 繁體中文

### 🪐 專案介紹
**Awesome Cosmos Explorer** 將 GitHub 上百花齊放的開源專案（AI、前端、遊戲引擎、創意代碼、系統終端、暗網安全、奇趣實驗）投射為一座 3D 賽博宇宙。透過流暢的視差旋轉、曲率躍遷流光、黑洞盲盒抽卡與 Web Audio 實時音效合成，打造如科幻電影般的開源寶藏探索體驗。

**特點：純前端零構建 (Zero-build)**，無需 `npm install` 或 `npm run build`，本地雙擊即可運行，直接拖曳到 **Cloudflare Pages Direct Upload (Drop)** 即刻發布。

### ✨ 核心特色
- **🌌 3D 璀璨星系視覺**：基於 Three.js 渲染的 7 大星域，具備動態星雲粒子團、自轉光環與脈衝星。
- **🚀 曲率躍遷穿梭 (Warp Speed)**：高速流光拉伸鏡頭，平滑縮放至星體表面並附帶時空穿梭音效。
- **🕳️ 黑洞引力抽卡 (Gravitational Discovery)**：引力漩渦探測隨機捕獲開源寶藏卡片，搭配專屬開牌慶典和弦。
- **✨ 專屬星座冊 (Constellation Log)**：點亮收錄心儀專案，在宇宙深空中連線繪製專屬星座，並可一鍵匯出 Markdown。
- **🔊 純 Web Audio 程序化音效**：瀏覽器即時算力合成科幻環境底噪與琉璃音階，零音訊外鏈依賴。
- **🔠 動態字體縮放**：支援適中 (17px)、放大 (19.5px) 與特大 (22px) 三段調節，並自動保存喜好。

### ☁️ Cloudflare Pages (Drop) 30 秒無痛發布
1. 登入 [Cloudflare Dashboard](https://dash.cloudflare.com/)。
2. 前往 **Workers & Pages** ➜ **Create application** ➜ 選擇 **Pages**。
3. 點選 **Upload assets (Direct Upload)**。
4. 將本專案資料夾或 `awesome-cosmos.zip` 直接拖曳進去。
5. 點擊 **Deploy site**，立即獲得專屬的 `*.pages.dev` 網址！

## 🇺🇸 English

### 🪐 Overview
**Awesome Cosmos Explorer** visualizes hundreds of legendary GitHub Awesome open-source repositories as an interactive 3D cyberpunk galaxy. Explore sectors across AI, Web Frameworks, Game Engines, Creative Coding, DevOps, Security, and Playful Experiments with smooth planetary navigation, warp speed hyperspace jumps, gravitational gacha, and procedural Web Audio synthesizers.

**Zero-build & Cloudflare Pages Ready**: No build step or bundler needed. Works out of the box locally and is ready for drag-and-drop deployment on Cloudflare Pages.

### ✨ Features
- **🌌 Immersive 3D Starfield**: 7 distinct cosmic sectors rendered with Three.js, featuring glowing nebulae, rotating planet rings, and pulsating stars.
- **🚀 Warp Speed Hyperspace**: Smooth camera transitions with warp streaks and dynamic acoustic glide effects.
- **🕳️ Gravitational Gacha**: Probe the black hole vortex to draw random open-source gems with fanfare chimes.
- **✨ Constellation Journal**: Bookmark favorites to draw radiant constellation lines across space and export to Markdown with one click.
- **🔊 Procedural Web Audio Engine**: Zero external audio assets; real-time synthesizer drone, crystalline bells, and hyperspace frequencies.
- **🔠 Accessibility Font Scaling**: Instant cycling between Normal (17px), Large (19.5px), and Huge (22px) modes with localStorage persistence.

### ☁️ 30-Second Cloudflare Pages (Drop) Deployment
1. Log in to [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Navigate to **Workers & Pages** ➜ **Create application** ➜ **Pages**.
3. Select **Upload assets (Direct Upload)**.
4. Drag and drop this folder or `awesome-cosmos.zip`.
5. Click **Deploy site** to instantly receive your live `*.pages.dev` URL.

## 🇯🇵 日本語

### 🪐 プロジェクト概要
**Awesome Cosmos Explorer** は、GitHubの膨大な「Awesome」オープンソースプロジェクト群を3Dサイバーパンク宇宙として可視化したインタラクティブ探査ツールです。AI、Web技術、ゲームエンジン、クリエイティブコーディング、システムツール、サイバーセキュリティなど、7つの星域を自由に飛び回り、ワープ航法やブラックホールガチャで未知の神リポジトリを発見できます。

**ゼロビルド・完全静的設計**：`npm build` 不要で、ファイルをそのまま開くだけで動作し、**Cloudflare Pages Direct Upload (Drop)** にドラッグ＆ドロップするだけで即座に公開可能です。

### ✨ 主な機能
- **🌌 3D星雲と天体レンダリング**：Three.js による7大星域、動的な星雲パーティクル、脈動するパルサーと輝く惑星。
- **🚀 ワープ速度ハイパースペース**：流光ストリーク演出と音響効果を伴うスムーズなカメラ移動。
- **🕳️ 重力ブラックホールガチャ**：時空を歪めてランダムにオープンソースの宝箱を引き当てる演出機能。
- **✨ オリジナル星座ブックマーク**：お気に入りプロジェクトを宇宙空間で繋げて独自の星座を描き、Markdown形式でエクスポート可能。
- **🔊 純粋なWeb Audioプロシージャル音響**：外部音声ファイルなしでブラウザがリアルタイム合成する環境ドローンやクリスタル音。
- **🔠 フォントスケーリング機能**：適正（17px）、拡大（19.5px）、特大（22px）の3段階切り替えに対応。

### ☁️ Cloudflare Pages（Drop）での簡単デプロイ
1. [Cloudflare Dashboard](https://dash.cloudflare.com/) にログイン。
2. **Workers & Pages** ➜ **Create application** ➜ **Pages** を選択。
3. **Upload assets (Direct Upload)** をクリック。
4. このプロジェクトフォルダまたは `awesome-cosmos.zip` をドラッグ＆ドロップ。
5. **Deploy site** をクリックすれば、数秒で専用の `*.pages.dev` サイトが公開されます！
